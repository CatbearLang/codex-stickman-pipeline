# Included examples

`../docs/demo.gif` is an excerpt of a generic 16-second example generated by the pipeline: Codex script and three native images, real Edge TTS narration, local montage and included ambient sound. It starts directly with the hook; no channel intro. This is not content from a private channel.

`script.json` is its structured input. `topics.txt` is a generic starter bank. Use `tools/demo.py` for the separate offline procedural diagnostic.

Generated illustrations can vary and require human review. This example demonstrates the workflow, not a guarantee of identical results on every account or topic.
